MEDIATION ENGINE - INSTALLER COMMANDS

    mng help
        Display this help message.
    mng validate
        Validate the installation and configuration.
    mng paths
        Display installation paths.
    mng start platform
        Start the platform using its configured JVM settings.
    mng start watchdog
        Start the watchdog using its configured JVM settings.
    mng exit
        Exit the installer shell.

If launchd already manages the platform and watchdog, use launchctl to manage
those processes rather than starting duplicate instances from this shell.

PLATFORM COMMANDS (run on the platform TCP connection, port 15000)

    mng help
        Show runtime commands supported by the connected JVM.
    mng health report platform
        Show the platform's internal service health.
    mng health report ec01
        Show the latest heartbeat and service health for ec01.
    mng start ec ec01
        Start ec01 through its watchdog.
    mng stop ec ec01
        Stop ec01 through its watchdog.
    mng restart ec ec01
        Restart ec01 through its watchdog.
    mng status
        Show the connected JVM's status.
    mng restart services all
        Restart all internal services in the connected JVM.
    mng shutdown services all
        Shut down all internal services in the connected JVM.
    mng kill
        Terminate the connected JVM. launchd may restart a managed JVM.

Replace ec01 with the configured EC ID. Keywords are case insensitive;
EC IDs retain their configured case. Every management command requires the
mng prefix.

On a direct EC TCP connection, use mng health report <that-ec-id> for its local
health report. Status, service commands, and kill also apply to that EC.

The installer shell and platform connection have separate command sets.
