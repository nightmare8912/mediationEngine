Welcome to the help menu.

Here is a list of commands that you can use, with its purpose:

    1. meng create user -u <username> -p <password>
        Creates a new user in the system, after which they can login.

    2. meng drop user -u <username>
        Drops the user from database, and they cannot login now

    3. meng help
        Displays help message

    4. meng exit
        Exits the shell

    5. meng initialize h2db
        Initializes the internal H2 database

    6. meng shutdown h2db
        Shuts down the connection pool of the internal database
